# Лабораторная работа №1

## «Молекулярно-динамическое исследование изотермического сжатия газа»

## Цель работы

Исследовать с помощью метода молекулярной динамики изотермическое сжатие газа, описываемого потенциалом Леннарда–Джонса, и оценить границы применимости данной модели в докритической, критической и сверхкритической областях.

В ходе работы необходимо:

1. Определить параметры потенциала Леннарда–Джонса для заданного вещества на основе экспериментальных данных.

2. Определить оптимальный размер системы для молекулярно-динамического моделирования. Критерии выбора:

   - достаточная точность получаемых термодинамических параметров;
   - приемлемое время расчёта.

3. Получить не менее трёх изотерм изотермического сжатия:

   - при температуре ниже критической;
   - при температуре, близкой к критической;
   - при температуре выше критической.

   Каждая изотерма должна содержать не менее 5 точек.

4. Сравнить результаты молекулярно-динамического моделирования с:

   - экспериментальными данными NIST;
   - уравнением состояния идеального газа.

5. Проанализировать полученные результаты и определить, в каких условиях потенциал Леннарда–Джонса позволяет адекватно описывать поведение исследуемого вещества, а в каких проявляются ограничения модели.

## На защиту необходимо представить

1. Отчёт в электронном виде с описанием основных этапов работы, полученными результатами и выводами.
2. Графики изотерм для трёх исследованных температур. На каждом графике должны быть представлены результаты:

   - молекулярно-динамического моделирования;
   - экспериментальные данные NIST;
   - расчёт по уравнению состояния идеального газа.

3. Код, использованный для определения параметров потенциала Леннарда–Джонса.
4. Входные и выходные файлы LAMMPS для каждой рассчитанной изотермы.
5. Код или файл, использованный для обработки и анализа результатов LAMMPS.

В отчёте для каждой серии расчётов необходимо указать основные параметры молекулярно-динамического моделирования: число частиц, шаг интегрирования, используемый ансамбль, длительность расчёта и параметры термостатирования. При выборе размера системы необходимо привести обоснование его достаточности с учётом точности получаемых термодинамических параметров и времени расчёта.

## Защита работы

При защите работы необходимо продемонстрировать понимание выполненного моделирования, умение объяснить физический смысл используемых методов и параметров, а также назначение основных команд входного скрипта LAMMPS и обрабатывающих программ. В частности, необходимо понимать, за что отвечают параметры системы, условия моделирования, используемый ансамбль, шаг интегрирования, параметры термостатирования и способы расчёта термодинамических величин.

Защита проводится до конца 8-й недели включительно. Работы, не защищённые в указанный срок, защищаются в зачётную неделю.
